Запуск

Нет ключа LLM в .env — модель недоступна, агент будет ехать по резервному плану.
Запуск занимает ~10–15 с: Gazebo, судья, агент.

Управление роботом

Клик по карте — цель (или точка маршрута в режиме «Маршрут»). Shift+клик — всегда точка маршрута. Доехав до точки, робот сам соберёт образец, если датчик покажет «рядом». В автономном режиме клик перехватывает управление у LLM.
